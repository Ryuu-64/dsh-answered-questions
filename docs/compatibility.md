# 兼容说明

## 接入方式

客户端通过 DSH 公共 Conversation 事件注册和 `conversation.chat.node` 插槽工作。
原生问答使用保存的 `tool/call`、`tool/result`、PTC 子调用及带有明确来源的延迟回复。匹配以调用编号为准。

DSH `0.2.1-rc.3` 的原生已回答问答由本插件补上完整聊天卡片。
`0.2.2-rc.3` 已有简短答案气泡；在完整卡片可用时，本插件隐藏对应气泡，避免重复。
对于延迟回答，使用 DSH 保存的完整题目与答案；记录缺失时保留可读的原生摘要。

选择卡适配 `@machine202502/dsh-choice@0.1.2`，通过同一插槽覆盖原卡片显示。
工具本身仍由 `dsh-choice` 提供。问答回看的 Host 服务验证会话、题目和选项后，通过 DSH 的消息队列提交答案。
普通用户消息与工具结果文本不会被猜测为选择。

## 已知边界

- 原生单选、多选和填写支持 DSH 已记录的文本。没有原始问题的历史摘要无法还原全部选项。
- `dsh-choice` 旧记录缺少明确关联，不能追溯恢复旧的选中状态。安装后经本插件提交的答案才带有可恢复的选择来源。
- 选择卡支持该版本工具的 2–8 个选项及「都不选」。尚未支持其他插件同名工具的不同参数格式。
- 多媒体沿用原选项地址或工具返回的媒体地址。媒体服务停机、源文件删除、远程地址过期时，图片或音频可能不可用；选择记录仍保留。
- 原生 plan-review 由 DSH 自己显示，本插件不接管计划审批。
- 所声明的精确版本之外不推断兼容性；Web 实测不等于 Electron 或 Tauri 的完整验证。
