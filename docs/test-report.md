# 0.1.0 浏览器验证记录

2026-11-17，在 Windows、Node.js 24.14.0 和 Chrome 157.0.8103.51 的无界面模式下验证。实际运行官方 DSH Web，使用独立的空白配置档、临时工作区和 Playwright 浏览器上下文。所有模型回答由本地固定响应服务提供；没有访问外部模型，也没有操作日常使用的 DSH 配置档或浏览器。

测试目标为本地运行的 DSH 页面及本插件；允许的改动仅为临时聊天、问题回答和临时服务重启。使用 `browser-qa` 的隔离和证据流程，授权范围为本次插件开发中的实现与验证。

每个原生问题在聊天中均只有一张本插件完整卡片。最终两次运行没有捕获到浏览器页面错误或失败的 JSON RPC 响应。截图检查确认选择卡展示全部文字、选中标记和选项说明，浅色窄屏没有横向裁切。

## 能力与边界

输入、截图、DOM、URL/视口、页面错误和网络响应检查均可用；没有进行完整无障碍审计、性能评测或录制浏览器轨迹。测试的是 Windows 上的官方 Web 宿主，不等同于 Electron/Tauri 桌面外壳测试。

本次浏览器场景没有覆盖图片放大、音频播放、长时间离线、排队答案取消、同一聊天多客户端同时提交、原生超时后的迟到回答，以及所有历史迁移情况。它们不计为浏览器测试通过；相应纯逻辑覆盖以仓库单元测试为准。

## 复现

先准备指定版本的官方 DSH npm 运行目录、`dsh-choice@0.1.2` 和已有的 Playwright/Chrome。测试器不会安装浏览器或依赖。

```text
npm ci --ignore-scripts --legacy-peer-deps
npm run build
node scripts/e2e.mjs --runtime <包含node_modules的DSH目录> --playwright <playwright/index.mjs> --choice <dsh-choice目录> --chrome <Chrome可执行文件> --restart true
```

省略 `--restart true` 时不执行服务重启场景。并行跑另一版本时，可加 `--base-port 45281`，避免与默认的三个环回端口冲突。测试结束会关闭浏览器和本次创建的服务，临时目录保留供检查。
